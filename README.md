# Voting Eligibility Checker

## About
A simple beginner project that checks whether person is above 18 or below.

## Concepts Used
- Variables
- User Input
- If-Else Statements
- Comparison Operators
- Basic Programming Logic

## How It Works
The program takes the user's age as input and checks
whether the age meets the required eligibility criteria.

## What I Learned

statements and taking input from the user.
